# Contributing

Please open an issue or pull request with the page or slide number, the proposed correction, and supporting evidence.

- State the model, hardware variant, precision, batch size, context length, and other assumptions needed by a calculation.
- Keep GB and GiB distinct, and distinguish theoretical bounds from measured performance.
- Prefer original papers and official hardware or framework documentation for factual claims.
- Label authored exercises and independently verified interview reports accurately.
- Preserve source attribution. Linked third-party materials remain subject to their respective terms.
- Keep the presentation in English and use readable academic formatting.

Before submitting site changes, run the build and link checks described in the README. Do not commit private data, local build directories, credentials, or temporary render outputs.
