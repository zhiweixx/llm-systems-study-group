# Week 4 presentation assets

The standalone deck is generated by `scripts/build_week4.py` from the editable SVG content in `scripts/week4/`. It follows the existing white-background, muted-blue academic design. The CSS and navigation were reused from the Week 3 overview; the source decks are not modified.

All diagrams are original teaching illustrations. Numerical observations in the routing questions, queue example, load-sweep table, and speculative-decoding timing example are explicitly hypothetical. No measured GPU performance figure is reproduced or invented. Primary-source links appear on individual slides and in `week-4-speaker-notes.md`.

The 30-slide sequence opens with six speculative-decoding teaching slides. The examples distinguish greedy verification from exact sampling, show why a rejected token invalidates its draft suffix, and connect accepted tokens to latency rather than treating acceptance rate alone as speedup. The remaining slides retain the serving case, cache and scheduling examples, questions, and benchmark lab.

`interactions.js` controls speculative verification and its timing comparison as well as prefix-block sharing and chunked scheduling. Print mode selects a complete explanatory state and restores the previous state afterward. The HTML embeds all its visual assets and has no runtime network dependency.

Run `scripts/check_week4.cjs` with Playwright and Chrome to check slide text bounds, overlaps, responsive fitting, offline resources, question/solution adjacency, step controls, and print-state restoration. Rendered screenshots still need visual review.
