# Week 3 presentation assets

The 50-slide deck uses original editable SVG diagrams generated by the Python modules in `scripts/week3/`. It follows the established white background, blue headings, and restrained academic layout. No external image, font, or JavaScript runtime is required for presentation.

- `base.css`: presentation layout, controls, responsive scaling, and print styling.
- `navigation.js`: slide navigation, overview, speaker notes, fullscreen, and print controls, adapted from the existing Week 2 runtime.
- `interactions.js`: step frames for the tensor-parallel MLP (slide 9), ring attention (26), and expert-routing examples (37). Print shows the completed state and then restores the previous state.

All diagrams and numerical profiles are authored teaching examples. The communication timing examples are hypothetical, not GPU benchmark results. Footer links identify the primary sources supporting the mechanisms; fuller assumptions appear in the notes. CP uses the user's Insu Jang article as supplemental reading alongside Ring Attention, DeepSpeed Ulysses, and Megatron documentation. MoE routing is based on the mechanisms described by Mixtral and the cited runtime documentation.

The expanded lessons cover pipeline bubbles and microbatch scheduling, TP/CP degree constraints, communication-aware placement, and multi-node CP/EP. Questions 1–2 are on slides 45 and 47, each followed by a solution; slides 49–50 contain the take-home exercise and reference solution.

Build with `.venv/bin/python scripts/build_week3.py`. Check browser layout and interactions with `node scripts/check_week3.cjs` in an environment with Playwright and Chrome.
